# 🔐 Password Generator

A simple and interactive **Password Generator** built using HTML, CSS, and JavaScript.

This project generates random 12-character passwords containing uppercase letters, lowercase letters, numbers, and special characters. It also provides a copy-to-clipboard feature to make copying generated passwords easier.

## 🚀 Features

- **Random Password Generation:** Generates a random password with 12 characters.
- **Mixed Characters:** Includes uppercase letters, lowercase letters, numbers, and special characters.
- **Copy to Clipboard:** Easily copy the generated password using the copy button.
- **Copy Notification:** Displays a notification when the copy button is clicked.
- **Simple UI:** Clean interface with CSS styling and Flexbox layout.

## 🛠️ Technologies Used

- HTML5 – Structure of the application.
- CSS3 – Styling, Flexbox, hover effects, and transitions.
- JavaScript – Password generation, event handling, and clipboard functionality.
- Font Awesome – Copy icon.

## ⚙️ How It Works

1. Click the **Generate** button.
2. JavaScript randomly selects characters from a predefined character set.
3. A 12-character password is generated and displayed in the input field.
4. Click the copy icon to copy the generated password.
5. A notification appears to indicate the copy action.
